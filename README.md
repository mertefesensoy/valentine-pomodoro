# Valentine Pomodoro

A cozy Pomodoro timer, now being rebuilt into a **couples study app**: two people pair once, study together on one shared timer, and watch their focus time grow into something cute. The v2 public name is still to be decided.

It began in January 2026 as a gift for Bengisu. Version 1.4.0 is on the App Store, the first release of the v2 rehaul; Android stays on 1.3.1.

| | |
|--|--|
| **Status** | v1.4.0 (Phase 1) is live on the App Store (since 2026-11-04). See the [roadmap](docs/roadmap/ROADMAP.md). |
| **Platforms** | iOS 16.4+. The web app comes in Phase 6. Android is deferred until Google Play's closed-test requirement can be met. |
| **Stack** | Expo SDK 58, React Native 0.88, React 19.3, TypeScript, Reanimated 4, CNG (native projects generated by EAS). |

## What it does today (v1.4.0)

- **Timer:** focus, short breaks and long breaks, drift-free (timestamp-based), with completion handled exactly once even if the app was killed.
- **Fly Mode (iOS):** a session as a flight between two real airports, with the plane moving along the great-circle route.
- **Stats:** today, all-time, a 7-day chart, a daily goal and a streak.
- **Love notes** after a focus session; a daily reminder with quiet hours; light and dark themes.

What v2 adds is specified, requirement by requirement, in the [SRS](docs/srs/SRS.md).

## Development

**Prerequisites**
- Node 22 or 24 and npm.
- An [Expo](https://expo.dev) account with access to the EAS project, for builds.
- **Expo Go can't run this app**, because it uses native modules (AdMob, maps). Use a development build.
- There is no Mac in the current setup. iOS builds come from EAS and are tested through TestFlight.

**Commands**

```bash
npm ci
npm run typecheck
npm run lint
npm test
node scripts/docs/check-docs.mjs
```

**Build** (needs the owner's go-ahead; see [RELEASE.md](docs/process/RELEASE.md))

```bash
npx eas-cli build --platform ios --profile production
```

Native `ios/` and `android/` folders are generated from `app.json` and are not committed.

## Privacy

[`privacy-policy.md`](privacy-policy.md) says exactly what the app collects, in English and Turkish. In short:

- **Without an account,** the timer, stats and notes stay on the phone. From 1.5.0, the app sends one anonymous report of how quickly it opened after a normal launch, which a Settings switch turns off.
- **With an account,** which exists only for pairing, Supabase keeps your name, your time zone and language, your pairing, your days while paired, and your notes to your partner, in Frankfurt. You can download it all or delete it in the app.
- **Other services:** Apple's iTunes Lookup API on iOS and GitHub Pages' `update.json` on Android, to check for a newer version; Apple Maps in Fly Mode; and Google AdMob, for capped ads, which are non-personalised.

There is no third-party analytics, and no tracking prompt (SRS NFR-PRIV-001/002).
